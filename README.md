#  AI Assistant - Flask + Gemini

A simple AI Assistant web application built with **Python, Flask, and Google's Gemini API**.

The application provides a web interface where users can send messages and receive AI-generated responses.

##  Features

-  Chat with an AI assistant
- Powered by Google's Gemini API
- Flask-based web application
-  Secure API key management using environment variables
- Simple and user-friendly interface
-  Real-time interaction with the AI assistant

##  Technologies Used

- **Python**
- **Flask**
- **Google Gemini API**
- **HTML**
- **CSS**
- **JavaScript**
- **python-dotenv**
